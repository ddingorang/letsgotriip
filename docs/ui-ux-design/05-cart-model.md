# 05 — 장바구니(담는 중인 여행) 모델

사용자 요청: *"아예 기본 일정을 만들고 거기에 추가하는 방식으로 하고 싶은데 장바구니"*

매번 계획→일차를 고르는 피커가 무겁다는 피드백에서 출발. 쇼핑 장바구니처럼
**담을 곳을 하나 정해두고 한 번 탭으로 담는** 모델로 전환한다.

## 핵심 개념: 활성 계획(active plan)

"담는 중인 여행"을 하나 기억한다(`localStorage`):
- `triip.activePlanId` — 담을 대상 계획 id
- `triip.activePlanTitle` — 버튼/FAB 라벨용 제목 캐시
- `triip.cartCount` — FAB 배지에 쓰는 담은 장소 수

활성 계획 결정 규칙(`plan` 스토어 `ensureActivePlan()`):
1. 저장된 활성 계획이 아직 존재하면 그대로 사용
2. 없으면 가장 최근(=id 큰) 계획을 활성으로
3. 계획이 하나도 없으면 기본 **"나의 여행"**(오늘~+2일)을 자동 생성

→ 사용자는 "기본 일정"을 따로 만들 필요 없이, 첫 담기에서 자동으로 생긴다.

## 인터랙션

### 장소 상세 — 분할 버튼(split button)
```
[ 🛒  ○○에 담기 | ▾ ]
```
- **본문 탭** → 활성 계획의 1일차에 바로 담기(`quickAddPlace`). 피커 없음.
  - 담은 뒤 토스트: `○○ N일차에 담았어요  ·  [여행 보기]`
  - 이미 담긴 장소면: `이미 ○○에 담겨 있어요`
- **▾ 캐럿** → 기존 계획/일차 선택 시트(다른 일정으로 바꿔 담기).
  - 시트에서 계획을 고르면 그 계획이 **활성 계획으로 고정**되어, 이후 한 번 탭이 거기로 간다.
- 버튼 라벨은 활성 계획 제목으로 갱신되며, 길면 10자+`…`로 자른다.

### 둘러보기 — 장바구니 FAB
홈·탐색·검색·장소상세에서 우하단에 떠 있는 FAB:
```
🛒 ○○여행  (배지: 담은 수)
```
- 탭하면 `/plan`(내 여행)으로 이동.
- 탭바가 있는 화면에선 탭바 위로 올라간다(`bottom: 64px`).
- 활성 계획이 없으면(=아직 아무것도 안 담음) 숨김.

## 기존 피커와의 관계
03·04 문서에서 만든 계획/일차 선택 바텀시트는 **버린 게 아니라 캐럿 뒤로** 들어갔다.
- 기본 경로: 한 번 탭(무마찰)
- 보조 경로: 캐럿 → 피커(정확히 어느 계획·일차인지 직접 고름)

## 검증(프리뷰 5174, demo@triip.com)
- 한 번 탭 담기 → 활성 계획 자동 선택, 토스트, cartCount 증가 ✓
- 라벨 갱신 + 긴 제목 말줄임 ✓
- 캐럿 → 피커(단일 계획이면 일차 선택으로 바로), 담기 → 토스트·시트 닫힘 ✓
- FAB: 탐색 화면 노출(배지 수), 탭 → /plan 이동, /plan에선 숨김 ✓
- localStorage 영속(`activePlanId`/`activePlanTitle`/`cartCount`) ✓

## 후속 — 구현 완료(2026-06-22)
담은 곳이 모두 1일차로 들어가므로 일차 재배치가 핵심. PlanView에 행 액션을 추가했다:
- 장소 행 **⋯ → 방문 시간 설정 / 다른 날로 이동 / 삭제** 바텀시트.
  - 다른 날로 이동: `movePlaceToDay`(단일 move 엔드포인트가 없어 대상에 add → 원본 delete 2단계).
  - 방문 시간: 빠른 칩(오전·점심·오후·저녁) + 네이티브 time input + 시간 지우기, `setPlaceVisitTime`(낙관적 PUT).
- 순서 변경/이동/삭제 결과 **토스트**, 세션당 1회 **편집 도움말 배너**.
- 검증: 프리뷰 5174에서 이동(1일차8→7·2일차6→7)·삭제·순서토스트·방문시간 모두 동작 확인.
